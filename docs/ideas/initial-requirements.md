# AIディベートアプリ - アイデアメモ

## このドキュメントの位置づけ

壁打ち・ブレストの成果物。正式な仕様書ではない。
フリーランスエンジニア（ジュニア）のポートフォリオとして開発するWEBアプリのアイデア。

---

## プロダクトコンセプト

**2つのAIペルソナが、ユーザーの設定したテーマについて議論し、結論を出すWEBアプリ。**

- ユーザーがペルソナ（名前・立場・性格）を2つ設定する
- テーマを与えると、AIが自律的にツールを使いながら議論を展開する
- 議論の過程（ツール使用・思考）がリアルタイムで画面に表示される
- 最終的に双方の論点を整理した結論が出力される

---

## なぜこのアプリを作るか

### ポートフォリオとして優れている理由

- **デモがしやすい**: センシティブなデータ不要、その場でテーマを変えてデモできる
- **非エンジニアにも伝わる**: 「AIが議論する」は一言で説明できる、見ていて面白い
- **技術的な深みがある**: マルチエージェント + ツールユースが自然に実現できる
- **差別化が明確**: 単なるチャットボット・RAGシステムとは明確に違う

## ターゲットユーザー（デモ対象）

- フリーランス案件の担当者（非エンジニアも含む）
- AI活用に興味があるが、どう使えばいいかわからない人
- 新しい技術デモを求めているスタートアップ・中小企業

## 主要機能

### MVP（1〜2週間で作る）

#### 1. ペルソナ設定
- ペルソナA・Bそれぞれに名前・立場・性格を自由入力
- 例: 「楽観的な経営コンサルタント」vs「慎重なリスクアナリスト」

#### 2. テーマ入力
- 議論させたいテーマを自由入力
- 例: 「AIベンチャーへの投資はすべきか」

#### 3. 議論の実行
- 2エージェントが交互に主張（3〜5往復）
- 各発言でツールを使用（下記参照）
- リアルタイムで発言・ツール使用が画面に表示される

#### 4. 結論の出力
- 双方の論点を整理してまとめる
- 最終的な結論または判断軸を提示

### ツール設計（MVP）

| ツール名 | 内容 | 期待効果 |
|----------|------|----------|
| Web検索 | 主張の根拠をリアルタイムで検索 | 説得力が増す、動いている様子が伝わる |
| ユーザーへの質問 | 前提条件が不明な時に人間に逆質問 | AIから質問される体験が新鮮で印象に残る |

### MVP後に追加する機能（候補）

- アップロード資料の読み込み（PDF等を参考資料として渡す）
- 司会AI（3人目のエージェントが議論を整理・結論を出す役割）
- 議論の優勢メーター（どちらが押しているかリアルタイム表示）
- 議論ターン数の設定
- 議論結果のエクスポート（Markdown/PDF）

## 技術スタック（確定）

- **バックエンド**: FastAPI（Python）
- **LLM**: Claude（claude-sonnet-4-6）via **AWS Bedrock**
  - Anthropic SDK の `AnthropicBedrock` クライアントを使用
  - AWS アクセスキーで認証
  - ポートフォリオとして「エンタープライズ向けAI連携」をアピールできる
- **エージェント実装**: Anthropic SDK の tool_use API を直接使用（フレームワークなし）
  - APIレベルの理解をアピールできる
  - LangChain等の抽象化レイヤーを挟まない
- **Web検索ツール**: Tavily API または SerpAPI（実装直前に選定）
- **フロントエンド**: HTML/CSS/JavaScript + SSE（Server-Sent Events）
  - リアルタイムで議論の進行を表示
  - シンプルだがデモ映えする
- **リアルタイム表示**: Server-Sent Events（SSE）

### 既存サービスとの違い

| | このアプリ | 通常のチャットAI | RAGシステム |
|--|--|--|--|
| エージェント数 | 2（対立構造） | 1 | 1 |
| ツール使用 | ◎ 可視化される | △ 見えない | ○ |
| ユーザー体験 | 観戦 + 介入 | 会話 | 検索 |
| デモのしやすさ | ◎ その場で設定 | △ | △ |
| 非エンジニアへの訴求 | ◎ | ○ | △ |
